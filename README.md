# homebrew-tap

Homebrew tap for [gitpic](https://github.com/tarnish233/gitpic-cli) and
[cloudot](https://github.com/tarnish233/cloudot).

```bash
brew install tarnish233/tap/gitpic
brew install tarnish233/tap/cloudot
```

The `gitpic` formula checks for a new GitHub Release every six hours. The
update can also be triggered manually from the Actions page.
